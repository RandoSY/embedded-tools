How to Run It

  1. Copy your BLE script to the Pico W as main.py and reset the board.
  2. First try opening this HTML directly as a local file in Chrome or Edge. Many Chromium setups treat file: as trustworthy for secure-context features.
  3. Open the page in Chrome or Edge, click Connect, and pick PicoW-UART.
  4. After connection, you should see the Pico’s tick N messages arrive once per second.

Fallback if direct-open is blocked

python -m http.server 8000
Then browse to http://localhost:8000/pico_w_ble_uart_console_singlefile_r1_1.html

Notes

  • This page talks to the standard Nordic UART Service used by your Pico script.
  • The browser acts as the BLE central; the Pico W script is the BLE peripheral.
  • If you later move to JSON messages, command packets, or tabs for sensors, this page is a good starting shell.
